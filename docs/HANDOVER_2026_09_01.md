## 1. 项目概况

- 上游 [pure_live](https://github.com/liuchuancong/pure_live) 的**个人自用修改版**，Android-only 纯净版，仅保留哔哩哔哩 / 斗鱼 / 虎牙 / 抖音四大平台。
- **当前版本**：`2.0.1+2004`（基于上游 v2.1.4 裁剪定制）
- **应用包名**：`com.superxyline.purelive`
- **应用名**：纯粹直播（纯净版）
- **目标平台**：Android（arm64 / arm32）
- **技术栈**：Flutter 3.47.0（`E:\codex\tools\flutter`）+ GetX（`lib/get` 源码副本，可直接改）+ 原生 Kotlin MainActivity（高刷/显示模式/后台保活/快捷方式 MethodChannel）

## 4. 本期（v2.0.2+2005）完成的全部工作

**弹幕列表礼物卡片：**
- 支持B站/斗鱼/虎牙/抖音四大平台礼物消息

## 5. 本期（v2.0.1+2004）完成的全部工作

### 4.1 弹幕屏蔽增强（v2.0.1 核心功能）

**正则表达式支持：**
- 以 `/` 开头和结尾，如 `/AB+\d{2,}/`
- 无效正则自动降级为普通关键词
- 支持完整正则语法（分组、量词、字符类等）

**通配符支持：**
- `*` 匹配任意字符序列
- `?` 匹配单个字符
- 如 `*游戏*` 匹配包含"游戏"的文本

**分词选择屏蔽：**
- 弹幕内容按标点和空格自动分词
- 以 `FilterChip` 标签显示，点击选择/取消
- 保留手动输入自定义关键词功能
- 关键词列表显示类型标签（`REGEX`紫色 / `WILDCARD`青色）

### 4.2 弹幕菜单UI适配

- **右侧面板使用Dialog组件**：自动应用app对话框主题（圆角24dp、surfaceContainerHigh背景、无阴影）
- **与app其他弹窗保持一致的视觉风格**

### 4.3 播放器交互优化

- **点击空白处切换UI**：使用 `toggleController()` 实现显示/隐藏切换
- **弹幕输入时控制条常显**：避免自动隐藏打断输入
- **菜单打开时底部栏保持显示**：线路/画质选择期间控制条不隐藏

### 4.4 局域网同步修复

- **修复发送方显示失败的问题**：统一使用 `/api/importData` 端点
- **与跨端传输功能保持一致**：两个同步功能使用相同的端点和数据格式

### 4.5 其他

- **移除快手和网易CC相关内容**：链接解析功能中删除不支持平台的介绍
- **README更新**：版本号和新增功能说明

## 6. 构建环境（⚠️ 必须遵守）

```bash
# 关键：pub get 必须用默认 pub 缓存（C:\Users\13017\AppData\Local\Pub\Cache）
export GIT_CONFIG_GLOBAL='E:\codex\tools\gitconfig_safedir'   # safe.directory 豁免

export FLUTTER_STORAGE_BASE_URL='https://storage.flutter-io.cn'
export GRADLE_USER_HOME='E:\codex\tools\.gradle'
export ANDROID_USER_HOME='E:\codex\tools\.android'
export JAVA_HOME='E:\codex\tools\jdk-17.0.2'
flutter pub get
flutter build apk --release --target-platform android-arm64 --split-per-abi  # ARM64
flutter build apk --release --target-platform android-arm --split-per-abi     # ARM32
```

- **不要 `git checkout pubspec.lock`**：lock 的 url 字段会在 pub.dev/pub.flutter-io.cn 间切换
- 产物：`build\app\outputs\flutter-apk\app-arm64-v8a-release.apk`（117.4MB）
- ARM32产物：`build\app\outputs\flutter-apk\app-armeabi-v7a-release.apk`（104.1MB）
